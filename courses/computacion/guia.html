Punto por punto

1. Cargar librerías

1 pto

Necesitas leer Excel, manipular datos y graficar:

library(readxl)   # leer Excel
library(dplyr)    # filter, select, mutate, arrange, group_by, summarise
library(tidyr)    # drop_na
library(ggplot2)  # gráficos
library(writexl)  # exportar a Excel (instalar antes con install.packages("writexl"))

# alternativa: library(tidyverse) carga dplyr+tidyr+ggplot2+readr de una vez,
# pero igual necesitas readxl y writexl aparte porque no vienen en el núcleo de tidyverse

2. Importar el Excel

1 pto
prestamos <- read_excel("prestamos_biblioteca.xlsx")
Recuerda: la ruta debe apuntar a donde tengas guardado el archivo en tu computador (o usar un proyecto de RStudio para que la ruta sea relativa).

3. Explorar los datos

1 pto

Cuatro funciones, una por cada sub-punto:

View(prestamos)      # a) ver la base completa en una pestaña
summary(prestamos)   # b) resumen estadístico (min, max, promedio, cuartiles)
head(prestamos)      # c) primeras filas
tail(prestamos)      # d) últimas filas

4. Estudiantes mayores de edad

2 ptos

Combina filter() (filas) + select() (columnas), y guarda en un objeto nuevo:

prestamos_mayores <- prestamos %>%
  filter(edad >= 18) %>%
  select(estudiante, edad)

5. Crear dias_proyectados

2 ptos

mutate() crea variables nuevas a partir de otras. Ojo: se trabaja sobre prestamos (el objeto original), no sobre prestamos_mayores:

prestamos_dias <- prestamos %>%
  mutate(dias_proyectados = dias_prestamo + 2)

6. Renombrar la variable

1 pto

rename() sigue el orden nombre_nuevo = nombre_viejo, y se aplica sobre prestamos_dias:

prestamos_dias <- prestamos_dias %>%
  rename(periodo_prestamo = dias_proyectados)

7. Eliminar filas con NA

2 ptos

drop_na() sin argumentos elimina cualquier fila que tenga al menos un valor faltante, en cualquier columna. Se aplica sobre el prestamos original:

prestamos_limpios <- prestamos %>%
  drop_na()

8. Crear costo_total

2 ptos

Otra vez mutate(), ahora con una fórmula de dos variables, sobre prestamos_limpios:

prestamos_limpios <- prestamos_limpios %>%
  mutate(costo_total = dias_prestamo * 500 + multa)

9. Ordenar por costo_total descendente

2 ptos

arrange(desc(...)) ordena de mayor a menor:

prestamos_limpios <- prestamos_limpios %>%
  arrange(desc(costo_total))

10. Agrupar por sede

2 ptos

group_by() + summarise(), usando el prestamos original (no el limpio):

prestamos %>%
  group_by(sede) %>%
  summarise(
    promedio_dias = mean(dias_prestamo, na.rm = TRUE),
    cantidad = n()
  )
na.rm = TRUE es útil por si prestamos original todavía tiene NA en dias_prestamo (evita que el promedio salga NA).

11. Gráfico de barras

2 ptos

Calcado del gráfico que ya hiciste en Sesión 14 agosto.R (el de ventas/producto/cantidad), solo cambiando las variables:

ggplot(prestamos, aes(x = libro, y = dias_prestamo)) +
  geom_col(fill = "steelblue") +   # elige el color que quieras
  labs(
    title = "Días de préstamo por libro",
    x = "Libro",
    y = "Días de préstamo"
  ) +
  theme_minimal() +
  theme(
    plot.title = element_text(hjust = 0.5),
    axis.title = element_text(hjust = 0.5)
  )
hjust = 0.5 es lo que centra el título y los títulos de los ejes — es el requisito que más se olvida.

12. Exportar a Excel

1 pto

Igual que el "Paso 5" de tu script de ejemplo:

write_xlsx(prestamos_limpios, "prestamos_procesados.xlsx")

Errores comunes que bajan nota

  • Trabajar sobre el objeto equivocado (por ejemplo, aplicar el punto 8 sobre prestamos en vez de prestamos_limpios). El enunciado especifica sobre qué objeto trabajar en cada punto — léelo dos veces antes de escribir el código.
  • Olvidar <- al guardar el resultado en el objeto nuevo (sin eso, el cálculo se muestra en pantalla pero no queda guardado).
  • Usar = en vez de == dentro de filter() (para comparar se usa doble igual).
  • Escribir mal el nombre de una columna (por ejemplo Edad en vez de edad — R distingue mayúsculas de minúsculas).
  • Olvidar theme(plot.title = element_text(hjust = 0.5)) para centrar el título del gráfico.
  • No correr el script completo de principio a fin antes de entregar (algo que funcionó suelto puede fallar si el orden de los bloques está mezclado).

Compara con "Sesión 14 agosto.R"

Resuelve primero los PDFs de ejercicios

Practica variaciones

Autoevalúate con preguntas tipo

Checklist final antes de subir a uvirtual

  • Las librerías cargan sin error (readxl, dplyr, tidyr, ggplot2, writexl — o tidyverse + las otras dos).
  • El objeto prestamos se creó correctamente desde prestamos_biblioteca.xlsx.
  • prestamos_mayores tiene solo estudiante y edad, y solo estudiantes de 18 años o más.
  • prestamos_dias tiene la columna periodo_prestamo (no dias_proyectados).
  • prestamos_limpios no tiene filas con NA, tiene costo_total, y está ordenado de mayor a menor costo.
  • El gráfico de barras tiene título, nombres de ejes, color de barras, theme_minimal(), y título y ejes centrados.
  • Se generó el archivo prestamos_procesados.xlsx.
  • El script completo corre de principio a fin sin errores (probado con "Run All").
  • Archivo .R guardado con nombre identificable y listo para subir.
