Clase 17

Función logarítmica

Definición, propiedades, gráficas y aplicaciones a interés compuesto.

Definición

Sea a un número positivo con a ≠ 1. La función logarítmica con base a, denotada loga, está definida por log_a x = y ⇔ a^y = x, con f : ℝ⁺ → ℝ. Es decir, loga(x) es el exponente al cual hay que elevar la base a para obtener x.

Forma logarítmicaForma exponencial
log₁₀ 100.000 = 510⁵ = 100.000
log₂ 8 = 32³ = 8
log₂ (1/8) = −32⁻³ = 1/8
log₅ s = r5ʳ = s

El logaritmo es la inversa de la exponencial; ambas son biyectivas.

Propiedades

  • a) log_a 1 = 0
  • b) log_a a = 1
  • c) log_a aˣ = x
  • d) a^(log_a x) = x
  • e) log_a(xy) = log_a x + log_a y
  • f) log_a(x/y) = log_a x − log_a y
  • g) log_a(x^y) = y·log_a x
  • h) log_a x = log_b x / log_b a (cambio de base)
Ejercicio

Encuentre el dominio de g(x) = 2 + log₅ x y trace su gráfica.

Solución: la gráfica de g se obtiene de la de f(x)=log₅x desplazada 2 unidades hacia arriba. Dom(f) = (0, ∞).

Dos logaritmos importantes

Logaritmo decimal (a=10): y = log₁₀x = log x  ·  Logaritmo natural (a=e): y = log_e x = ln x

Ejemplo

Encuentre el dominio de f(x) = ln(4 − x²).

Solución: ln x está definida para x>0. dom(f) = {x | 4−x²>0} = {x | |x|<2} = (−2, 2).

Aplicaciones — modelo de aprendizaje

Si una tarea se aprende a nivel P₀, tras t meses el recordatorio P satisface log P = log P₀ − c·log(t+1).

a) Despejando: P = P₀ / (t+1)^c.
b) Con P₀=90, c=0,2: a los 2 meses P≈72; al año (t=12) P≈54.

Fórmulas de interés

  • Simple (1 año): A = P(1+r)
  • Capitalizado n veces/año: A(t) = P(1+r/n)^(nt)
  • Capitalizado continuamente: A(t) = P·e^(rt)
Ejemplo

$5000 al 5% anual — ¿cuánto tarda en duplicarse?

a) Semestral: 5000(1,025)^(2t)=10000 ⟹ t ≈ 14,04 años
b) Continua: 5000e^(0,05t)=10000 ⟹ t = ln2/0,05 ≈ 13,86 años

Pon en práctica

a) Grafique f(x)=log₃x, g(x)=log₄x, f(x)=2log x, g(x)=1+log x   b) Dominio de f(x)=log₁₀(x+3) y f(x)=log₅(8−2x)   c) $1000 al 4% anual continuo: ¿tiempo para llegar a $4000?

Clase 18

Preliminares de límite de funciones

Intuición numérica, definición ε–δ, límites laterales.

Ejemplo introductorio: f(x)=x²−x+2 cerca de x=2 — al aproximarse por ambos lados, f(x)→4, sin necesidad de evaluar en x=2: lím_{x→2} (x²−x+2) = 4.

Observación fundamental

El valor al que se aproxima x no necesita pertenecer al dominio de f. El límite describe el comportamiento de f cerca de un punto, no en ese punto.

Ejemplo: f(x)=(x−1)/(x²−1), no definida en x=1. Mediante tabla de valores se conjetura lím_{x→1} f(x) = 1/2.

Ejemplo — un límite que no existe

lím_{x→0} sen(π/x). Con x=1/n (n entero): sen(nπ)=0, lo que sugeriría erróneamente que el límite es 0. Pero con x=1/(n+½), la función vale ±1: la función oscila entre −1 y 1 infinitamente y el límite no existe.

Lección: analizar una sucesión particular de puntos puede engañar — se requiere analizar todos los valores próximos a a.

Definición ε–δ

lím_{x→a} f(x) = L  ⇔  ∀ε>0, ∃δ>0 : 0<|x−a|<δ ⇒ |f(x)−L|<ε

Para cualquier margen de error ε alrededor de L, existe un radio δ tal que si x está en (a−δ,a+δ) (excluyendo a), entonces f(x) cae en (L−ε,L+ε).

Ejemplo — demostración por definición

Demostrar que lím_{x→2} (4x−5) = 3.

|(4x−5)−3| = 4|x−2| < ε ⟺ |x−2| < ε/4 ⟹ se toma δ = ε/4.
Si 0<|x−2|<δ: |(4x−5)−3| = 4|x−2| < 4δ = ε. ∎

Límites laterales

Derecha: lím_{x→a+} f(x)=L ⇔ ∀ε∃δ: a<x<a+δ ⇒ |f(x)−L|<ε
Izquierda: lím_{x→a−} f(x)=L ⇔ ∀ε∃δ: a−δ<x<a ⇒ |f(x)−L|<ε

Teorema: lím_{x→a} f(x)=L existe ⇔ lím_{x→a−} f(x) = lím_{x→a+} f(x) = L
Ejemplo — función con salto

En x=2: lím izq=3, lím der=1 → no existe (3≠1). En x=5: lím izq=lím der=2 → lím=2, aunque f(5)=3≠2 (el valor puntual no afecta el límite).

Desafíos de la clase

a) g(x)=(x²+x−6)/|x−2|: calcule los límites laterales en x=2 y determine si existe lím_{x→2} g(x).
b) Determine m para que exista lím_{x→0} f(x), con f(x)=[sen x−sen(mx)]/x si x≤0, f(x)=m√(4x²+x³)/(2x) si x>0.

Clase 19

Álgebra de límites

Propiedades operatorias, formas indeterminadas, límites al infinito.

Propiedades (con lím f=L, lím g=M, λ∈ℝ)
  • a) lím[f±g] = L±M
  • b) lím[λf] = λL
  • c) lím[f·g] = L·M
  • d) lím[f/g] = L/M  (M≠0)
  • e) lím[f]ⁿ = Lⁿ
  • f) lím ⁿ√f = ⁿ√L  (si n par, L>0)

Válidas solo cuando los límites existen por separado.

Observación: si lím f(x) resulta en la forma k/0 con k≠0, el límite no existe.

Formas indeterminadas

0/0  ·  ∞/∞  ·  ∞−∞  ·  0·(±∞)  ·  0⁰  ·  1^∞  ·  ∞⁰

No bastan por sí solas para determinar si el límite existe.

Límites al infinito — fórmulas útiles

  • a) lím_{x→+∞} 1/x = 0
  • b) lím_{x→∞} 1/xⁿ = 0, ∀n∈ℕ
  • c) lím_{n→+∞} rⁿ = 0, si |r|<1
Pon en práctica

b) lím_{x→∞} (2x³−5x²+x−3)/(x³−2x−3)
c) lím_{x→∞} (2x³−4x²+x)/(3x³+x+4)
d) lím_{x→+∞} (−4x)/(x³+3x+1)
e) Encuentre α∈ℝ tal que lím_{x→+∞} xᵅ/(x²+x+1) exista.
f) lím_{x→+∞} x/√(x²+1) y lím_{x→−∞} x/√(x²+1)
Clase 20

Teoremas interesantes de límite

Sandwich, cambio de variable, límites notables algebraicos, exponenciales y logarítmicos.

Teorema del Sandwich

Si g(x) ≤ f(x) ≤ h(x) ∀x∈I, x≠a, y lím_{x→a} g(x) = lím_{x→a} h(x) = L, entonces lím_{x→a} f(x) = L.

Ejemplo

Calcule lím_{x→∞} (x+1)/(x²−1) con Sandwich.

Para x>2: x²−1>x²/2, x+1<2x ⟹ 0 < (x+1)/(x²−1) < 4/x. Ambas cotas → 0.

lím = 0
Ejemplo — cuando el Sandwich no concluye

f satisface x²−x ≤ f(x) ≤ x²+x ∀x∈ℝ.

lím_{x→0} f(x): ambas cotas → 0 ⟹ lím_{x→0} f(x) = 0.
lím_{x→1} f(x)/x: dividiendo entre x>0 cerca de 1, x−1 ≤ f(x)/x ≤ x+1 → cotas 0 y 2 (distintas): el Sandwich no permite concluir.

Moraleja

El Sandwich solo funciona cuando ambas cotas tienen el mismo límite.

Teorema de cambio de variable

Si lím_{x→a} f(x)=L, lím_{x→x₀} g(x)=a, y g(x)≠a cerca de x₀ (salvo en x₀), entonces lím_{x→x₀} (f∘g)(x) = L. Intuición: con u=g(x), cuando x→x₀, u→a.

Ejemplo

lím_{x→27} (x−27)/(∛x−3). Con u=∛x, x=u³: (u³−27)/(u−3) = (u−3)(u²+3u+9)/(u−3) → 27.

Límites notables algebraicos
  • a) lím_{x→a} (xⁿ−aⁿ)/(x−a) = n·aⁿ⁻¹
  • b) lím_{x→∞} k/xⁿ = 0 (k≠0, n≥1)
  • c) lím_{x→∞} P(x)/Q(x) = aₙ/bₘ si mismo grado; 0 si deg P<deg Q; ±∞ si deg P>deg Q

Ejemplos: lím_{x→2}(x⁴−16)/(x−2)=4·2³=32  ·  lím_{x→∞}(5x³−2x+1)/(3x³+x²−7)=5/3  ·  lím_{x→∞}(4x²−1)/(x³+2)=0

El número e y sus formas equivalentes

lím_{x→∞} (1+1/x)^x = e  ·  lím_{x→0+} (1+x)^(1/x) = e  ·  lím_{x→∞} (1+a/x)^x = eᵃ

Ejemplo resuelto — forma 1^∞

lím_{x→∞} [(2x²+x+1)/(2x²−1)]^x

Se reescribe la base como 1+(x+2)/(2x²−1) y se fuerza la forma (1+1/n)^n con el exponente ajustado. Resultado: e^(1/2).

Límites logarítmicos notables

a) lím_{x→0} (a^(kx)−1)/x = k·ln(a)  ·  b) lím_{x→0} (e^(kx)−1)/(kx) = 1

Ejemplo

a) lím_{x→0} (e^(−4x)−1)/x = −4·1 = −4
b) lím_{x→0} (5ˣ−2ˣ)/x = ln5 − ln2 = ln(5/2)

Pon en práctica
1a) lím_{x→∞}[(4x−3)/(4x+5)]^(3x+1)
1b) lím_{x→∞}[(2x+1)/(2x−3)]^(x+5)
1c) lím_{x→∞}[(x−1)/(x−4)]^(2x+3)
1d) lím_{x→0}[(x²+1)/(2x+1)]^(1/x)
1e) lím_{h→0}[log(x+h)+log(x−h)−2log x]/h²
2) Seis límites de práctica adicionales (potencias, raíces, cocientes de exponenciales)

Clase 21

Continuidad

Definición formal, composición de funciones continuas, discontinuidades reparables e irreparables.

Definición

f es continua en a ⇔ se cumplen: a) f(a) está definida   b) lím_{x→a} f(x) existe   c) lím_{x→a} f(x) = f(a).

Si alguna falla, f es discontinua en a (a: punto de discontinuidad).

Interpretación intuitiva

Una función es continua en a si su gráfica puede trazarse sin levantar el lápiz en ese punto: no hay saltos, agujeros ni asíntotas verticales.

Teorema

Si f, g continuas en a: también f±g, f·g, f/g (con g(a)≠0). Si f continua en b y lím_{x→a} g(x)=b: lím_{x→a} f(g(x)) = f(lím_{x→a} g(x)) = f(b).

Ejemplos — límites de composiciones

a) lím_{x→1} ln[(x²−1)/(x−1)] = ln(lím(x+1)) = ln 2

b) lím_{x→2} √[(x³−8)/(x−2)] = √(lím(x²+2x+4)) = √12 = 2√3

Discontinuidades reparables e irreparables

Irreparable: lím_{x→x₀} f(x) no existe. Ej: f(x)=1/x (x≠0), f(0)=100 — lím_{x→0} 1/x no existe.

Reparable: lím_{x→x₀} f(x)=L existe, pero f(x₀) no está definida o f(x₀)≠L. Ej: f(x)=(x²−1)/(x−1) en x₀=1 — lím=2, pero f(1) no definida.

Extensión por continuidad

Si lím_{x→x₀} f(x)=L existe: g(x)=f(x) si x≠x₀, g(x₀)=L es continua en x₀ — "reparar" la discontinuidad.

Ejercicio — continuidad por partes (tipo PEP)

Clase 22

Asíntotas

Horizontales, verticales y oblicuas.

Definición

Una asíntota ℓ es una recta tal que la distancia entre (x,f(x)) y ℓ puede hacerse tan pequeña como se desee, sin que la curva la toque.

  • Horizontal: y=y₀ ⇔ lím_{x→±∞} f(x) = y₀
  • Vertical: x=x₀ ⇔ lím_{x→x₀±} f(x) = ±∞
  • Oblicua: y=mx+b, con m = lím_{x→±∞} f(x)/x,   b = lím_{x→±∞} [f(x)−mx]

Puede haber hasta dos asíntotas oblicuas; solo existen cuando no hay asíntota horizontal en esa dirección.

Ejemplos

a) f(x) = (x+2)/(3x+1)  ·  b) f(x) = 4x/(x²−9)

Desafíos

f(x) = (x−1)/(x²−4): determine todas las asíntotas.

f(x) = (c·x²+x−3)/(6x²−5x−1), x≠1, x≠−1/6. Si y=1/3 es asíntota horizontal, determine c∈ℝ; luego halle las asíntotas verticales para ese c.

Pon en práctica
1) f(x) = x/(x²−1)
2) f(x) = x²/(x−1)
3) f(x) = x/√(x²+1)
4) f(x) = (x²−1)/√(x²+1)
